# Data Model: Investments MVP

All tables live in the user data store and use soft delete like upstream tables.
All ids are generated by the existing uuid container (new types `SECURITY`, `INVESTMENT_TRADE`, `SECURITY_PRICE`).

## Derived (not stored)

- **Holding**: quantity, total cost, average cost, realised P&L, dividends, latest price, value, unrealised P&L and percent, XIRR, warnings.
- **Portfolio summary**: base-currency totals, XIRR, allocation by type and currency, `unconvertedCurrencies`.

## Validation rules

- Buy and sell: quantity > 0, price > 0, fees >= 0.
- Dividend: amount > 0, quantity and price zero.
- Replay of the security's full history must never go below zero quantity.
- Security delete is refused while any non-deleted trade exists.
- Currency must pass the existing `validCurrency` validator.
